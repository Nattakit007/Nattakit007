### Current Project

**[Closed-Loop PID Controller](https://github.com/Nattakit007/Close-Loop)**

Currently building a closed-loop control system on STM32, working through:

* Feedback systems
* PID control
* Controller tuning
* Sensor feedback
* System response
* Real-world hardware behavior

The goal is not just to make the code work, but to understand what is actually happening between the controller, hardware, and physical system.
